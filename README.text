# Personal Websitw
این پروژه یک صفحه شخصی ساده است که با هدف یادگیری طراحی و ساخت وب سایت ایجاد شده است.
در این صفحه، اطلاعات کلی، معرفی کوتاه و نمونه ای از طراحی وب نمایش داده میشود.

## Project Description
این وب سایت به صورت استاتیک طراحی شده و شامل بخش معرفی، توضیحات کوتاه درباره 
علاقمندی ها و مهارت ها می باشد. تمرکز اصلی پروژه بر چیدمان مناسب، خوانایی محتوا و 
استفاده صحیح از HTML و CSS است.

## Technologies Used
HTML5
CSS3

## P roject Structure
ساختار اصلی ضفحه:index.html
استایل دهی و طراحی ضفحه:style.css
توضیحات و معرفی پروژه:README.text

## How to Run
برای مشاهده پروژه، کافی است فایل را با مرورگر کروم یا فایرفاکس باز کنید.

هدف از ساخت این پروژه:

آماده سازی نمونه کار برای صفحه شخصی
